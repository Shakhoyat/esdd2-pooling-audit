\begin{abstract}
Component-level audio anti-spoofing scores speech and environmental components on separate axes. An untouched recording has no separately generated component: on both axes it is a \emph{structural zero}, not a missing value. The ESDD2 evaluation plan nonetheless pools these clips with genuine \emph{bona fide} mixtures. This rule distorts the reported Equal Error Rate (EER): varying only the constant score assigned to structural zeros moves a fixed model's environmental EER between $0.5382$ and $0.1412$. We prove that weighted-area summaries such as AUC survive this pooling while EER admits no aggregation rule; published pooled EERs determine none of $55$ pairwise comparisons among eleven challenge systems. No label-free per-clip score reduction recovers the component-only value, so the correction belongs in the protocol. Evaluating each component only where it applies recovers it exactly; a reader using only the submitted scores comes within $0.0068$ rather than $0.2246$. Code: \url{https://github.com/Shakhoyat/esdd2-pooling-audit}.
\end{abstract}

\begin{keywords}
audio anti-spoofing, component-level detection, evaluation protocols,
equal error rate, ROC analysis
\end{keywords}

\section{Introduction}
\label{sec:intro}

Audio deepfake detection focuses not only on whether a recording is manipulated, but also on identifying which component has been manipulated. Partial-spoof detection localizes manipulation in time~\cite{partialspoof}, whereas component-level detection localizes it by source, evaluating a speech component and an environmental component on entirely separate axes~\cite{compspoof2026,esdd2,pcmix2026}.
This separation matters because a forgery may fabricate only one component while the other remains genuine, and a system that names the fabricated component says more than a single binary verdict.

\textbf{Structural zeros vs.\ sampling zeros.} A pristine, untouched audio recording inherently has no separate speech or environment component. In contrast, a \emph{bona fide} mixture contains separate components that could have been generated independently. Zero-inflated and hurdle models draw exactly this line. An untouched recording is a \emph{structural} zero because the component does not apply to it. A \emph{bona fide} mixture is a \emph{sampling} zero because the component applies, but it happens to be genuine. Pooling the two is known to bias estimates~\cite{he2014}. Throughout this paper, we use \emph{structural zero} for these inapplicable pristine captures; in CompSpoofV2, they are the ``class 0'' (\texttt{original}) category.
The ESDD2 evaluation plan states in Table~I that these structural zeros (Class 0) are mapped to the \emph{bona fide} class for both speech and environmental sounds~\cite{esdd2plan}, and the scorer released with the challenge baseline implements this exact rule. We are therefore not exposing an unstated or hidden convention. Rather, this paper shows that the stated rule, which combines structural zeros with sampling zeros on the same \emph{bona fide} side, invalidates the metric. Keeping the model fixed and changing only the constant value assigned to these clips changes the reported environmental EER from $0.5382$ to $0.1412$ (\S\ref{sec:exp}). A gap of nearly $0.40$ therefore opens under a rule every team follows identically: the plan fixes how class~0 is labeled, but not the score a system assigns to it, nor the range that score lives in.

\vspace{2pt}\noindent \textbf{Contributions.} (i) Because the structural zeros enter the positive class while the negative set is untouched, the Receiver Operating Characteristic (ROC) curves combine point by point (Fig.~\ref{fig:pooling}); we prove that a ROC summary can be aggregated under this pooling if and only if it is a monotone transformation of a weighted area. AUC satisfies this, the Equal Error Rate (EER) does not. (ii) We give the sharp identified set for the component-only EER given the published pooled EER and the class share. Across eleven published challenge systems this leaves all $55$ pairwise comparisons undetermined on both axes. (iii) We show that any label-free per-clip score reduction settles on a different fixed point, so participants cannot recover the component-only EER. (iv) The correction must therefore occur at the protocol level: organizers, who already hold the class partition, can evaluate each axis strictly where it applies, fixing the metric via a single-line scorer update that burdens no participant.

The empirical setting is the ESDD2 challenge~\cite{esdd2} and its CompSpoofV2 corpus~\cite{compspoof2026}. Four of the five classes are mixtures whose components each carry a provenance label. The fifth, \texttt{original}, is an untouched capture and acts as a structural zero; on the evaluation split these make up $53.2\%$ of the environmental \emph{bona fide} side ($w_0=0.5323$ in the notation of \S\ref{sec:unrec}). The challenge ranks on Macro-F1 and reports the three EERs as diagnostics~\cite{esdd2plan}; the diagnostics are nonetheless the numbers on which component detectors are compared in print.

\section{Metric identifiability under component pooling}
\label{sec:unrec}

Fix a component axis with negative set $\mathcal{N}$ and positive side $\mathcal{P} =
\mathcal{P}_0 \sqcup \mathcal{P}_{\mathrm{a}}$, where $\mathcal{P}_0$ collects the inputs the axis
does not describe; write $w_0 = |\mathcal{P}_0|/|\mathcal{P}|$ and $w_{\mathrm{a}} = 1-w_0$. The
published protocol scores $\mathcal{P}$ against $\mathcal{N}$, a reader removing the convention
scores $\mathcal{P}_{\mathrm{a}}$ against \emph{the same} $\mathcal{N}$. Only the positive side
changes, so with $\mathrm{FRR}_S$ the false-rejection rate on $S$,
\begin{equation}
\mathrm{FRR}_{\text{pub}}(\tau) \;=\; w_0\,\mathrm{FRR}_0(\tau) \;+\; w_{\mathrm{a}}\,\mathrm{FRR}_{\mathrm{a}}(\tau).
\label{eq:mix}
\end{equation}

Because $\mathcal{N}$ is shared, the threshold at a given false-acceptance rate $t$ is a functional
of $\mathcal{N}$ alone, so the same weights carry to the curves,
\begin{equation}
\mathrm{ROC}_{\mathrm{pub}}(t) \;=\; w_0\,\mathrm{ROC}_0(t) \;+\; w_{\mathrm{a}}\,\mathrm{ROC}_{\mathrm{a}}(t),
\label{eq:roc}
\end{equation}
and pooling a structural zero class is a convex combination in ROC space. The question is which
summaries commute with it.

\vspace{2pt}\noindent\textbf{Theorem 1 (collapsibility).} \emph{Let $T$ be a ROC summary,
continuous, non-decreasing under pointwise dominance and strictly so under strict dominance, on a convex class $\mathcal{R}$
whose image $T[\mathcal{R}]$ is an interval and in which every $R$ is strictly dominated by, and strictly dominates, curves attaining every value of $T[\mathcal{R}]$ above and below $T(R)$. Then $T$ admits an aggregation rule $T_{\mathrm{pub}} = \varphi(T_0,
T_{\mathrm{a}}, w_0)$ for all curves and all $w_0$ if and only if $T = g \circ L$ with $g$
continuous and strictly monotone and $L[\mathrm{ROC}] = c + \int_0^1 \mathrm{ROC}\,dW$ for a fixed
finite non-negative Borel measure $W$, in which case $\varphi$ is the quasi-arithmetic mean generated by $g^{-1}$.}

\begin{proof}
\emph{Sufficiency.} With $T=g\circ L$ and $w_0+w_{\mathrm{a}}=1$ the constant is absorbed, so $L$ is
affine under mixing; writing $L=g^{-1}\!\circ T$ and applying $g$ gives the rule with
$\varphi(x,y,w)=g\big(w\,g^{-1}(x)+(1-w)g^{-1}(y)\big)$.

\emph{Necessity.} Fix $w$ and set $x\oplus y=\varphi(x,y,w)$ on $I=T[\mathcal{R}]$. Mixing is
idempotent, so $x\oplus x=x$; $\oplus$ is strictly increasing in each argument because mixing
preserves pointwise dominance; and it is bisymmetric, since $(A\oplus B)\oplus(C\oplus D)$ and
$(A\oplus C)\oplus(B\oplus D)$ are both $w^2A+w(1-w)(B+C)+(1-w)^2D$. Continuity is inherited from
$T$, and the richness hypothesis carries all four to $I^4$. Acz\'el~\cite[\S6.4]{aczel1966} then gives a
continuous strictly monotone $k_w$ and $\alpha(w)\in(0,1)$ with $x\oplus y=k_w^{-1}\big(\alpha(w)
k_w(x)+(1-\alpha(w))k_w(y)\big)$. Mixing at $v$ after $w$ is mixing at weights $vw,\,v(1-w),\,1-v$,
so $\{\oplus_w\}$ is mutually bisymmetric, which for quasi-arithmetic means forces a common generator $k$~\cite[Chs.~17--18]{aczel1989}; idempotence and the same composition then make $\alpha$ multiplicative and
continuous, so $\alpha(w)=w$. Hence $L:=k\circ T$ is affine on $\mathcal{R}$ and continuous in the
sup norm, so it extends to a continuous affine functional on the closed convex hull of $\mathcal{R}$
in $C[0,1]$; by the Riesz representation theorem every such functional is $c+\int_0^1\mathrm{ROC}\,dW$
for a finite signed Borel $W$, and monotonicity of $T$ forces $W\ge 0$. Take $g:=k^{-1}$.
\qedhere
\end{proof}

\vspace{2pt}
\noindent\emph{Relation to prior work.} The integral class is not new~\cite{wieand1989}, and
characterizations of the same shape exist for confusion counts~\cite{prati2026}, association
measures~\cite{kenah2025}, and fairness auditing under unobserved protected
class~\cite{kallus2019}. Those aggregate over groups carrying their own negatives. A positive
population mixed against a common reference is known to give \eqref{eq:roc}~\cite{gonen2013}; what
is new is the converse, which summaries admit any aggregation rule, and that splitting the positive
side against a \emph{shared} negative set puts a fixed point outside the class. This also separates
our setting from selective prediction~\cite{elyaniv2010}, where the model chooses to abstain, rather
than the evaluation protocol pooling inapplicable inputs.

\vspace{2pt}
The theorem sorts the summaries in routine use. Area under the curve, partial area, and
true-positive rate at a fixed false-acceptance rate are of this form, as is a detection cost at a
\emph{fixed} threshold. The equal error rate is not, nor is a minimum detection cost (a minimum of
functions affine in the share, hence concave in it) nor Youden's index (a maximum, hence convex).
Measured over the seven systems of \S\ref{sec:exp} and both axes, every summary the theorem calls
collapsible has a residual below $10^{-15}$ and every one it does not has a residual of at least
$1.4\times10^{-4}$ against the weighted mean; taking $W$ Lebesgue recovers the area, whose largest
residual over the fourteen checks is $2.22\times10^{-16}$~\cite{hanley1982}.
The residual is an exact algebraic difference, not a statistical test. An equal error rate is a
fixed point of $\mathrm{FAR}=\mathrm{FRR}$ rather than an
integral against the curve, and the fixed point of a convex combination is not the combination of
the fixed points. Two curves sharing a crossing but differing to its left mix with a third curve to
different crossings, so no $\varphi$ exists for EER.

\vspace{2pt}\noindent\textbf{Theorem 2 (sharp partial identification).} \emph{A published table
fixing $w_0$ and $\mathrm{EER}_{\text{pub}}$ confines the component-only value to}
\begin{equation}
\Big[\max\Big(0,\tfrac{\mathrm{EER}_{\text{pub}} - w_0}{w_{\mathrm{a}}}\Big),\;
      \min\Big(1,\tfrac{\mathrm{EER}_{\text{pub}}}{w_{\mathrm{a}}}\Big)\Big],
\label{eq:interval}
\end{equation}
\emph{and both endpoints are attained, so the interval is the sharp identified set given $(w_0,\mathrm{EER}_{\text{pub}})$.}

\noindent Write $\tau^\ast$ for the threshold at which the published rates cross, so
$\mathrm{FAR}(\tau^\ast) = \mathrm{FRR}_{\text{pub}}(\tau^\ast) = \mathrm{EER}_{\text{pub}}$. Evaluating
\eqref{eq:mix} there, with $\mathrm{FRR}_0(\tau^\ast) \in [0,1]$ the only freedom, gives
$\mathrm{FRR}_{\mathrm{a}}(\tau^\ast) \in [(\mathrm{EER}_{\text{pub}} - w_0)/w_{\mathrm{a}},\,
\mathrm{EER}_{\text{pub}}/w_{\mathrm{a}}]$. Because $\mathcal{N}$ is shared the false-acceptance
rate is common to both components, so $\mathrm{FAR}_{\mathrm{a}}(\tau^\ast) =
\mathrm{EER}_{\text{pub}}$; since $\mathrm{FAR}$ falls and $\mathrm{FRR}_{\mathrm{a}}$ rises in $\tau$, the component-only crossing $\mathrm{EER}_{\mathrm{a}}$ lies between
$\mathrm{FAR}_{\mathrm{a}}(\tau^\ast)$ and $\mathrm{FRR}_{\mathrm{a}}(\tau^\ast)$. As
$(\mathrm{EER}_{\text{pub}} - w_0)/w_{\mathrm{a}} \le \mathrm{EER}_{\text{pub}} \le
\mathrm{EER}_{\text{pub}}/w_{\mathrm{a}}$ whenever $\mathrm{EER}_{\text{pub}} \le 1$, that bracket
is contained in \eqref{eq:interval}; intersecting with $[0,1]$ gives the stated form. Both
directions are checked numerically in the released code.

For every sampled value in \eqref{eq:interval}, endpoints included, the released code builds an
admissible system matching both crossings to $10^{-12}$. Conditioning additionally on the other published cells of a
particular submission constrains the construction further; there we exhibit a witness for the lower
endpoint only, so under that stronger conditioning \eqref{eq:interval} is an outer bound. Bounding a component functional
under a two-component mixture is classical~\cite{horowitz1995}; \eqref{eq:interval} bounds from a
single published scalar. The reference baseline's environmental row on the \emph{evaluation} split
has $w_0=0.5323$ and $\mathrm{EER}_{\text{pub}}=0.4336$, so \eqref{eq:interval} returns
$[0,\,0.9271]$, that is $93\%$ of the range, containing the true $0.2090$ along with almost
everything else.

On the \emph{test} split, across the eleven systems publishing component EERs in the challenge
overview, \eqref{eq:interval} determines \emph{none} of the $\binom{11}{2}=55$ pairwise comparisons
on either axis. Every interval has lower endpoint $0$, so all eleven share a common sub-interval and
every strict ordering of the eleven remains feasible. After publication, the component-only EER is
unrecoverable.

\section{Limits of per-clip score reduction}
\label{sec:method}

Section~\ref{sec:unrec} shows that a reader cannot recover the component-only EER from a published pooled table. Disclosure does not help: even if teams reported their fill value $c$, the pooling could not be undone. The submission format admits one scalar per axis, so per-clip scores must be reduced before scoring, and no reduction rule that does not use the withheld partition targets the component-only value. The organizer, who holds the partition, recovers it exactly (\S\ref{sec:necessity}); the participant cannot.

\subsection{Applicability signal in the submission format}

The official submission format requires a predicted class and three scores, including a
score for the pristine \texttt{original} class~\cite{esdd2plan}. While this is not an explicit
``applicability'' flag, it is a strong signal: on the reference system, this
score separates the structural zeros with an AUC of $0.9964$. Let $\gamma_a$
denote the probability that axis $a$ applies, and let $d_a$ denote the model's
authenticity score for that component. With one score per axis, the two must be combined as
$\tilde{s}_a = \gamma_a d_a + (1-\gamma_a)c$ for a constant fill value $c$.

No canonical choice of $c$ reproduces either value of interest. On the reference system's environmental axis, with its scores on their native scale, the published pooled EER is $0.4336$ and the component-only EER is $0.2090$; $c=0$ yields $0.4654$, $c=0.5$ yields $0.1307$, and an oracle gate on the ground-truth partition also yields $0.1307$, since a perfect gate only sharpens the atom at $c$. Only $c=\tau_{\mathrm{a}}^\ast$, fixed by the withheld labels, could land on $0.2090$ (Proposition~3), and the released scorer misses even that: as $c$ rises past $0.0119$ its value steps from $0.4631$ to $0.1970$, the closest any constant comes.

\subsection{Why no reduction can work}

\vspace{1pt}\noindent\textbf{Proposition 3.} \emph{Under any gate and constant fill $c$, the pooled EER lies between the fixed points of $\mathrm{FAR}=w_{\mathrm{a}}\mathrm{FRR}_{\mathrm{a}}$ and $\mathrm{FAR}=w_0+w_{\mathrm{a}}\mathrm{FRR}_{\mathrm{a}}$, and equals the component-only EER only when the atom sits at the component crossing of the evaluation split, a threshold fixed by the withheld labels.}

\noindent A reduction can move the atom but cannot remove rows from $\mathcal{P}$, which the protocol fixes. From \eqref{eq:mix}, placing the atom above every threshold gives $\mathrm{FRR}_0=0$ and the crossing $\mathrm{FAR}=w_{\mathrm{a}}\mathrm{FRR}_{\mathrm{a}}$; placing it below gives $\mathrm{FRR}_0=1$ and $\mathrm{FAR}=w_0+w_{\mathrm{a}}\mathrm{FRR}_{\mathrm{a}}$. Between these thresholds the pooled crossing falls inside a jump of height $w_0$ and equals $\mathrm{FAR}(c)$, so it coincides with the component-only crossing only at $c=\tau_{\mathrm{a}}^\ast$, a function of the withheld labels. Since $w_{\mathrm{a}}<1$, the label-free choice $\mathrm{FRR}_0=0$ sits strictly below the component-only fixed point.

\vspace{2pt}
The divergence is visible in practice. On the reference system's environmental axis ($w_{\mathrm{a}}=0.4677$), ranking every structural-zero row above every threshold yields an EER of $0.1307$, as does the fixed point of $\mathrm{FAR}=w_{\mathrm{a}}\mathrm{FRR}_{\mathrm{a}}$, while the true component-only value is $0.2090$. A label-free reduction therefore settles on a different target rather than approaching the component-only value. Zhou and Wang~\cite{zhou2026eer} show a related invariance under monotone score transformations with the support fixed; Proposition~3 is the complement: adding structural zeros moves the fixed point by an amount only the withheld labels determine. Reporting AUC instead would sidestep the distortion, but EER remains the primary operating-point metric in anti-spoofing~\cite{asvspoof2021,asvspoof5}.

\subsection{Necessity of protocol-level correction}
\label{sec:necessity}

Proposition~3 bounds what a participant can do, and requiring an explicit applicability flag would add a field the organizers do not need. The corpus already defines the structural zero partition, and the official baseline computes the same indicator to mask class~$0$ in its loss. Since the organizers run the scorer, each axis can be evaluated on the annotated subset alone, a single-line change that leaves the submission format untouched. Where the partition is unavailable at scoring time, as in cross-corpus evaluation or deployment, the component-only EER is unidentifiable and a summary that aggregates under pooling (Theorem~1) should be reported instead.

\section{Experiments}
\label{sec:exp}
\subsection{Setup}

CompSpoofV2~\cite{compspoof2026,esdd2} provides $175{,}361$ training and $24{,}864$ validation clips; we analyse the $27{,}605$-clip evaluation split, whose labels were released after the challenge and whose spoofed components include generators unseen in training. All mixture classes are $16$\,kHz mono; the structural-zero class is heterogeneous in sample rate and channel count, which \S\ref{sec:confounders_metric_recovery} treats as a confounder. Our systems are frozen encoders with linear or attentive probes, layers chosen on a generator holdout, each trained at three seeds: BEATs and EAT linear probes, a BEATs attentive head, and a two-encoder probe reading BEATs for the environmental axis and XLS-R for speech. SSLAM and XLS-R linear probes enter only the check of \S\ref{sec:unrec}. The reference system is the released baseline, the only system publishing per-clip scores, so \S\ref{sec:acoustic_vs_pooling} and \S\ref{sec:confounders_metric_recovery} are single-system results.

Holding a system fixed and changing only the constant $c$ swings its reported environmental EER by up to $0.3970$ (Table~\ref{tab:spread}); under the component-only protocol the spread is identically zero.

The instability comes from the point mass: all structural zeros receive one constant score, and the reported EER depends on which side of the operating threshold that mass falls. The evaluation plan requests confidence scores without specifying a range, and its own worked example lists values such as $1.22$, $-1.54$ and $-1.89$~\cite{esdd2plan}, so unbounded logits are within the rules. For a probability-valued system, $c=0$ sits at the bottom of the range and the mass is rejected in full ($\mathrm{FRR}_0=1$): BEATs and EAT report $0.5382$ and $0.5400$. For a logit-valued system $c=0$ is an interior point, the attentive head and two-encoder spanning $[-25.0, 24.9]$ and $[-26.0, 34.4]$ on this axis, and the position of the mass relative to the threshold is incidental. It even varies with the seed: at $c=0.5$ the attentive head's seeds report between $0.1550$ and $0.4706$, while its component-only value stays between $0.1545$ and $0.1611$.

The two-encoder's near-invariance (a spread of $0.0031$) is the same artifact seen from the other side: its constants all lie within $0.026$ of the boundary beyond which the mass is accepted, so every cell sits within $0.0032$ of the Proposition~3 floor. That is a property of an uncalibrated score range, not evidence of a robust protocol.

\subsection{Acoustic difficulty versus pooling artifacts}
\label{sec:acoustic_vs_pooling}

A natural objection is that environmental spoofing is simply harder to detect, so the higher pooled error reflects the model, not the protocol. A controlled ablation on the reference system separates the two. Evaluated only on mixture classes, where genuine component annotations exist, the environmental and speech heads reach comparable EERs of $0.2090$ and $0.1906$, an intrinsic difference of only $0.0184$. Reintroducing structural zeros under the benchmark mapping raises the environmental EER by $0.2246$ but the speech EER by only $0.0087$, so the reported $0.2343$ gap decomposes exactly:
\begin{equation}
\label{eq:gap_decomposition}
\Delta_{\mathrm{total}} = \Delta_{\mathrm{pooling}} + \Delta_{\mathrm{intrinsic}} = 0.2159 + 0.0184 = 0.2343,
\end{equation}
where pooling alone ($0.2246 - 0.0087 = 0.2159$) accounts for over $92\%$ of the disparity.

The severity of the distortion is governed by the weighted false-rejection gap $w_0(\mathrm{FRR}_0-\mathrm{FRR}_a)$, evaluated at each axis's pooled operating point. On the speech axis ($w_0=0.3991$) this gap is $0.0169$ and the metric is nearly stable; on the environmental axis ($w_0=0.5323$) it widens to $0.3381$, driving the inflation. Because reference training explicitly masks class~$0$ across both loss functions, neither head received supervision on these instances: their output there is unspecified behaviour, not a measured deficiency. Masking is not idiosyncratic, either. The official baseline routes \texttt{original} clips away from both component detectors by construction~\cite{compspoof2026}, and at least one top-five submission masks both component losses on them, because component labels are defined only for mixtures~\cite{sit2026}.

One might instead train the environment head to emit \emph{bona fide} on class~0, matching the mandated mapping. We ran this: supervising both component heads on class~0, all else fixed, lowers the pooled environmental EER by $0.20$ across three seeds and two frozen-BEATs feature configurations, with no gain in component-only detection. The heads learn to recognize pristine captures (the environmental score's AUC for class~0 rises from $0.10$ to $0.71$), not synthesized environments, and the pooled value settles within $0.008$ of the Proposition~3 floor. It is still not a function of component performance: Table~\ref{tab:spread} shows the pooled number moving by $0.40$ under the fill value alone while the component-only value stays fixed.

Applicability looks easy to detect, but much of that ease is a format artifact. A trivial baseline using file-format heuristics alone reaches an $\mathrm{F}_1$ of $0.9635$, because $93\%$ of structural zeros deviate from $16$\,kHz mono. Restricting to the $525$ structural zeros that are $16$\,kHz mono, scored against the $20{,}150$ mixtures of the split, that detector falls to chance ($\mathrm{AUC}=0.5000$) while the reference system's own \texttt{original} score holds $\mathrm{AUC}=0.9957$. Every mixture is $16$\,kHz mono, so this cohort removes the encoding cue and $0.9957$ reflects the applicability signal itself. The reference system separates this class at an AUC of $0.9964$ overall, yet the protocol still charges it an environmental EER of $0.4336$.

Table~\ref{tab:endtoend} outlines what an external reader can recover from outside the scoring
process. We set $\gamma_a = 1-\sigma(s_{\mathrm{o}})$, with $s_{\mathrm{o}}$ the submitted
\texttt{original} score and $\sigma$ the logistic function, and score each axis over
$\{x:\gamma_a(x)\ge\tfrac12\}$, at a precision of $0.999$ and a recall of $0.943$. The absolute
deviation from the component-only value falls by $97\%$ on the environmental axis and by $78\%$ on
the speech axis, and sweeping the gate threshold from $0.1$ to $0.9$ moves the environmental error
only between $0.0036$ and $0.0096$. The gate fits no parameters, but it runs on the full evaluation
split, where the format cue helps it, so this row may overstate what a reader recovers; the
organizer's route uses no gate and is unaffected. The point is not that systems should report this signal, but that an outside reader can \emph{approximately} audit what the protocol obscures, while the organizer, holding the partition, recovers it exactly at no cost. The fix belongs inside the scorer.

\section{Conclusion}
\label{sec:conc}

Component-level anti-spoofing routinely meets pristine inputs on which an axis does not apply. Pooling these structural zeros with genuine samples against a shared negative set leaves area-based summaries valid and distorts threshold-based ones: the environmental EER of a fixed model moves by nearly $0.40$ under the mandated rule, and published comparisons become unidentifiable. No label-free score reduction restores the component-only value, so the correction belongs in the protocol. Organizers already hold the applicability partition and should evaluate each axis where it applies, a single-line scorer change that leaves the submission format untouched.
