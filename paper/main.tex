\begin{abstract}
Component-level audio anti-spoofing scores speech and environmental components on separate axes. An untouched recording has no separately generated component: on both axes it is a structural zero, not a missing value. The ESDD2 evaluation plan nonetheless pools these clips with genuine bona fide mixtures. This rule distorts the reported Equal Error Rate (EER): varying only the constant score assigned to structural zeros moves a fixed model's environmental EER between $0.5382$ and $0.1412$. We prove that weighted-area summaries such as AUC survive this pooling while EER admits no aggregation rule; published pooled EERs determine none of $55$ pairwise comparisons among eleven challenge systems. No label-free per-clip score reduction recovers the component-only value, so the correction belongs in the protocol. Evaluating each component only where it applies recovers it exactly; a reader using only the submitted scores comes within $0.0068$ rather than $0.2246$.
\end{abstract}

\begin{keywords}
audio anti-spoofing, component-level detection, evaluation protocols,
equal error rate, ROC analysis
\end{keywords}

\section{Introduction}
\label{sec:intro}

Audio deepfake detection focuses not only on whether a recording is manipulated, but also on identifying which component has been manipulated. Partial-spoof detection localizes manipulation in time~\cite{partialspoof}, whereas component-level detection localizes it by source, evaluating a speech component and an environmental component on entirely separate axes~\cite{compspoof2026,esdd2,pcmix2026}.
This separation is important because a forgery may involve only one component, while the other components remain genuine. A system that successfully identifies which specific component was fabricated provides far more utility than one that simply outputs a single binary verdict.

An original recording has no separate speech or environment component, whereas a bona fide mixture has components that could have been generated independently. Zero-inflated and hurdle models draw exactly this line: the recording is a \emph{structural zero}, because the component does not apply to it, and the mixture a \emph{sampling zero}, because the component applies but happens to be genuine; pooling the two biases estimates~\cite{he2014}. We use structural zero for these inapplicable recordings, the class 0 (\texttt{original}) category of CompSpoofV2.
The evaluation protocol explicitly dictates how these zeros are handled. The ESDD2 evaluation plan states in Table~I that these structural zeros (Class 0) are mapped to the bona fide class for both speech and environmental sounds~\cite{esdd2plan}, and the released scorer enforces this exact rule. We are therefore not exposing an unstated or hidden convention. Rather, this paper shows that the stated rule, which combines structural zeros with sampling zeros and treats both as part of the same bona fide class, invalidates the metric. Keeping the model architecture completely fixed and changing only the constant value assigned to these clips changes the reported environmental EER from $0.5382$ to $0.1412$. A gap of nearly $0.40$ therefore opens under a rule every system follows identically: the plan fixes how class~0 is labeled, but not the score a system assigns to it, nor the range that score lives in.

\vspace{2pt}\noindent \textbf{Contributions: } (i) Because the structural zeros enter the positive class while the negative set is untouched, the Receiver Operating Characteristic (ROC) curves combine point by point (Fig.~\ref{fig:pooling}); we prove that a ROC summary can be aggregated under this pooling if and only if it is a monotone transformation of a weighted area. For AUC this recovers a known mixture identity~\cite{gonen2013}; the Equal Error Rate (EER) falls outside the class, and no aggregation rule for it exists. (ii) We give the sharp identified set for the component-only EER given the published pooled EER and the class share. Across eleven published challenge systems this leaves all $55$ pairwise comparisons undetermined on both axes. (iii) We show that any label-free per-clip score reduction settles on a different fixed point, so the component-only EER cannot be recovered from a submitted score file. (iv) Because label-free reduction fails, the correction must occur at the protocol level. The class partition is already available where the scorer runs, so each axis can be evaluated strictly where it applies, fixing the metric through a single-line scorer update and leaving the submission format untouched.

The empirical setting is the ESDD2 challenge~\cite{esdd2} and its CompSpoofV2 corpus~\cite{compspoof2026}. Four of the five classes are mixtures whose components each carry a provenance label. The fifth, \texttt{original}, is an untouched recording and acts as a structural zero; on the evaluation split these make up $53.2\%$ of the environmental bona fide side ($w_0=0.5323$ in the notation of \S\ref{sec:unrec}). The challenge ranks on Macro-F1 and reports the three EERs as diagnostics~\cite{esdd2plan}; the diagnostics are nonetheless the numbers on which component detectors are compared in print.

\section{Metric identifiability under component pooling}
\label{sec:unrec}

Fix a component axis with negative set $\mathcal{N}$ and positive side $\mathcal{P} =
\mathcal{P}_0 \sqcup \mathcal{P}_{\mathrm{a}}$, where $\mathcal{P}_0$ collects the inputs the axis
does not describe; write $w_0 = |\mathcal{P}_0|/|\mathcal{P}|$ and $w_{\mathrm{a}} = 1-w_0$. The
published protocol scores $\mathcal{P}$ against $\mathcal{N}$, a reader removing the convention
scores $\mathcal{P}_{\mathrm{a}}$ against the same $\mathcal{N}$. Only the positive side
changes, so with $\mathrm{FRR}_S$ the false-rejection rate on $S$,
\begin{equation}
\mathrm{FRR}_{\text{pub}}(\tau) \;=\; w_0\,\mathrm{FRR}_0(\tau) \;+\; w_{\mathrm{a}}\,\mathrm{FRR}_{\mathrm{a}}(\tau).
\label{eq:mix}
\end{equation}

Because $\mathcal{N}$ is shared, the threshold at a given false-acceptance rate $t$ is a functional
of $\mathcal{N}$ alone, so the same weights carry to the curves,
\begin{equation}
\mathrm{ROC}_{\mathrm{pub}}(t) \;=\; w_0\,\mathrm{ROC}_0(t) \;+\; w_{\mathrm{a}}\,\mathrm{ROC}_{\mathrm{a}}(t),
\label{eq:roc}
\end{equation}
and pooling a structural zero class is a convex combination in ROC space. Equation~\eqref{eq:roc}
is not itself new. G\"onen~\cite{gonen2013} derives the same mixture identity for a marker whose
diseased population is heterogeneous and whose non-diseased sample is shared, and reads the area off
it directly. That settles one summary. The question is which others commute with the mixing.

\vspace{2pt}\noindent\textbf{Theorem 1 (collapsibility): } \emph{Let $T$ be a ROC summary,
continuous, non-decreasing under pointwise dominance and strictly so under strict dominance, on a convex class $\mathcal{R}$
whose image $T[\mathcal{R}]$ is an interval and in which every $R$ is strictly dominated by, and strictly dominates, curves attaining every value of $T[\mathcal{R}]$ above and below $T(R)$. Then $T$ admits an aggregation rule $T_{\mathrm{pub}} = \varphi(T_0,
T_{\mathrm{a}}, w_0)$ for all curves and all $w_0$ if and only if $T = g \circ L$ with $g$
continuous and strictly monotone and $L[\mathrm{ROC}] = c + \int_0^1 \mathrm{ROC}\,dW$ for a fixed
finite non-negative Borel measure $W$, in which case $\varphi$ is the quasi-arithmetic mean generated by $g^{-1}$.}

\begin{proof}
Sufficiency is immediate: $L$ is affine under mixing, so applying $g$ gives
$\varphi(x,y,w)=g(w\,g^{-1}(x)+(1-w)g^{-1}(y))$. For necessity, fix $w$: then $\varphi$ is an
idempotent, bisymmetric mean on $T[\mathcal{R}]$, strictly increasing by the richness hypothesis, hence
quasi-arithmetic~\cite[\S6.4]{aczel1966}; composing mixings forces a common generator $k$ and weight
$w$~\cite[Chs.~17--18]{aczel1989}, so $k\circ T$ is affine and the integral form follows by Riesz
representation. The full argument is in \texttt{PROOFS.pdf} at the repository of footnote~\ref{fn:code}.
\end{proof}

\vspace{2pt}\noindent\textbf{Lemma: } \emph{If $T$ admits an aggregation rule $\varphi$ and
$T(R_0)=T(R_0')$, then $T(wR_0+(1-w)S)=T(wR_0'+(1-w)S)$ for every $S\in\mathcal{R}$ and every $w$,
because both sides equal $\varphi(T(R_0),T(S),w)$.}

\vspace{2pt}\noindent\textbf{Proposition 2: } \emph{The equal error rate, the minimum detection
cost and Youden's index admit no aggregation rule.}

\begin{proof}
Let $A$, $B$ and $S$ join $(0,0)$ to $(1,1)$ by straight segments through the interior breakpoints
$(\tfrac25,\tfrac35)$; $(\tfrac3{11},\tfrac12),(\tfrac25,\tfrac35)$; and $(\tfrac27,1)$. All
three are concave, hence equal to their own convex hulls. Curves $A$ and $B$ share an equal error
rate of $\tfrac25$ yet differ as curves ($\mathrm{AUC}$ $\tfrac35$ against $\tfrac{34}{55}$), and
mixing each with the \emph{same} $S$ at $w=\tfrac12$ gives $\tfrac27$ and $\tfrac3{11}$; both
pooled crossings fall on curve vertices, so they are exact rather than interpolated. A second
triple, through $(\tfrac13,\tfrac23)$; $(\tfrac16,\tfrac12),(\tfrac13,\tfrac23)$; and
$(\tfrac15,\tfrac45)$, shares a minimum detection cost and an index of $\tfrac13$ at equal priors
and unit costs, and pools to $\tfrac7{24}$ against $\tfrac4{15}$ and to $\tfrac5{12}$ against
$\tfrac7{15}$. Each pair contradicts the Lemma, so no $\varphi$ exists; on the same curves every
weighted area has residual exactly zero. A third triple, in the released code, separates the minimum detection cost at the ASVspoof 5 cost parameters.
\end{proof}

\vspace{2pt}
\noindent\textbf{Relation to prior work: } The integral class is not new~\cite{wieand1989}, and
characterizations of the same shape exist for confusion counts~\cite{prati2026} and association
measures~\cite{kenah2025}. Those aggregate over groups that carry their own negatives, where even the area
acquires cross-group terms~\cite{matos2026}; \eqref{eq:roc} splits the positive side against a shared negative
set, so the cross terms vanish and only the fixed point is left outside the class. Nor is this selective
prediction~\cite{elyaniv2010}, where the model abstains. Within anti-spoofing, the t-DCF was introduced because
the EER operating point does not reflect application requirements~\cite{kinnunen2020tdcf}, and the t-EER removes
its free parameters in a tandem setting~\cite{kinnunen2024teer}; both change the operating point or the cost
model while holding the evaluation population fixed, whereas here the population itself carries rows to
which the axis does not apply.

\vspace{2pt}
The theorem sorts the summaries in routine use. Area under the curve~\cite{hanley1982}, partial area, and
true-positive rate at a fixed false-acceptance rate are of this form; a detection cost evaluated at
a \emph{fixed} operating point aggregates directly by \eqref{eq:mix}, though it is a functional of
the threshold rather than of the curve. Proposition~2 places the equal error rate, the minimum
detection cost and Youden's index outside the class. A minimum over thresholds is not an
integral against the curve, and that is the form the summaries this field ranks on take: ASVspoof
has ranked on the \emph{minimum} normalised t-DCF since 2019~\cite{kinnunen2020tdcf}, ASVspoof 5
ranks on a minimum detection cost~\cite{asvspoof5}, and the architecture-agnostic
a-DCF~\cite{shim2024adcf} shares it. \S\ref{sec:convention_sensitivity} measures the resulting
distortion at the ASVspoof 5 cost parameters.
Measured over both axes of seven systems, the five in Table~\ref{tab:spread} plus SSLAM and
XLS-R probes, every summary the theorem calls collapsible has a
residual below $10^{-15}$ and every one it does not exceeds $10^{-4}$ against the weighted mean; taking $W$ Lebesgue recovers the area.
The residual is an exact algebraic difference, not a statistical test. An equal error rate is a
fixed point of $\mathrm{FAR}=\mathrm{FRR}$ rather than an
integral against the curve, and the fixed point of a convex combination is not the combination of
the fixed points.

\vspace{2pt}\noindent\textbf{Theorem 3 (sharp partial identification): } \emph{A published table
fixing $w_0$ and $\mathrm{EER}_{\text{pub}}$ confines the component-only value to}
\begin{equation}
\Big[\max\Big(0,\tfrac{\mathrm{EER}_{\text{pub}} - w_0}{w_{\mathrm{a}}}\Big),\;
      \min\Big(1,\tfrac{\mathrm{EER}_{\text{pub}}}{w_{\mathrm{a}}}\Big)\Big],
\label{eq:interval}
\end{equation}
\emph{and both endpoints are attained, so the interval is the sharp identified set given $(w_0,\mathrm{EER}_{\text{pub}})$.}

\noindent At the published crossing $\tau^\ast$, where $\mathrm{FAR}(\tau^\ast)=\mathrm{FRR}_{\text{pub}}(\tau^\ast)=\mathrm{EER}_{\text{pub}}$,
\eqref{eq:mix} with $\mathrm{FRR}_0(\tau^\ast)\in[0,1]$ confines $\mathrm{FRR}_{\mathrm{a}}(\tau^\ast)$ to
$[(\mathrm{EER}_{\text{pub}}-w_0)/w_{\mathrm{a}},\,\mathrm{EER}_{\text{pub}}/w_{\mathrm{a}}]$, and the shared negatives give
$\mathrm{FAR}_{\mathrm{a}}(\tau^\ast)=\mathrm{EER}_{\text{pub}}$; as $\mathrm{FAR}$ falls and $\mathrm{FRR}_{\mathrm{a}}$ rises in
$\tau$, $\mathrm{EER}_{\mathrm{a}}$ lies between the two, inside \eqref{eq:interval}. The released code checks both
directions and, for every sampled value, endpoints included, builds an admissible system matching both
crossings to $10^{-12}$; the full proof is in \texttt{PROOFS.pdf}. Conditioning also on a submission's other
published cells, we exhibit a witness for the lower endpoint only, so there \eqref{eq:interval} is an outer
bound. Bounding a component functional under a mixture is classical~\cite{horowitz1995}; \eqref{eq:interval}
bounds from one published scalar. For the reference baseline's environmental row on the evaluation split
($w_0=0.5323$, $\mathrm{EER}_{\text{pub}}=0.4336$) it returns $[0,\,0.9271]$, $93\%$ of the range, containing
the true $0.2090$ along with almost everything else.

On the test split, across the eleven systems publishing component EERs in the challenge
overview, \eqref{eq:interval} determines none of the $\binom{11}{2}=55$ pairwise comparisons
on either axis. Every interval has lower endpoint $0$, so all eleven share a common sub-interval and
every strict ordering of the eleven remains feasible. After publication, the component-only EER is
unrecoverable.

\section{Limits of per-clip score reduction}
\label{sec:method}

Section~\ref{sec:unrec} shows that a reader cannot recover the component-only EER from a published pooled table. A natural response is that the issue is one of disclosure: if the constant fill value $c$ were reported, the pooling could be undone. This section shows otherwise. The submission format admits one scalar per axis, so per-clip scores must be reduced before scoring, and no reduction rule that avoids the withheld partition targets the component-only value. Where the partition is available at scoring time the value is recovered exactly (\S\ref{sec:necessity}); from a submitted score file alone it is not.

\subsection{Applicability signal in the submission format}
\label{sec:applicability}

Let $\gamma_a$
denote the probability that axis $a$ applies (read off a submission as $1-\sigma$ of its \texttt{original} score), and let $d_a$ denote the model's
authenticity score for that component. Since the format requires exactly one score per axis, these values
must be combined as
$\tilde{s}_a = \gamma_a d_a + (1-\gamma_a)c$,
where $c$ is a constant fill value.

No canonical choice of $c$ reproduces either value of interest. On the reference system's environmental axis the published pooled EER is $0.4336$ and the component-only EER is $0.2090$; on that system's native score scale $c=0$ yields $0.4654$ and $c=0.5$ yields $0.1307$. An oracle gate handed the ground-truth partition reproduces the corresponding constant-fill column exactly, since a perfect gate sets $\gamma_a=0$ on every structural zero and therefore only sharpens the atom already sitting at $c$. Only $c=\tau_{\mathrm{a}}^\ast$, fixed by the withheld labels, could land on $0.2090$ (Proposition~4), and the released scorer misses even that: as $c$ rises past $0.0119$ its value steps from $0.4631$ to $0.1970$, the closest any constant comes.

\subsection{Impossibility of label-free score reduction}

\vspace{1pt}\noindent\textbf{Proposition 4: } \emph{Under any gate and constant fill $c$, the pooled EER lies between the fixed points of $\mathrm{FAR}=w_{\mathrm{a}}\mathrm{FRR}_{\mathrm{a}}$ and $\mathrm{FAR}=w_0+w_{\mathrm{a}}\mathrm{FRR}_{\mathrm{a}}$, and equals the component-only EER only when the atom sits at the component crossing of the evaluation split, a threshold fixed by the withheld labels.}

\noindent A reduction can move the atom but cannot remove rows from $\mathcal{P}$, which the protocol fixes. From \eqref{eq:mix}, placing the atom above every threshold gives $\mathrm{FRR}_0=0$ and the crossing $\mathrm{FAR}=w_{\mathrm{a}}\mathrm{FRR}_{\mathrm{a}}$; placing it below gives $\mathrm{FRR}_0=1$ and $\mathrm{FAR}=w_0+w_{\mathrm{a}}\mathrm{FRR}_{\mathrm{a}}$. Between these thresholds the pooled crossing falls inside a jump of height $w_0$ and equals $\mathrm{FAR}(c)$, so it coincides with the component-only crossing only at $c=\tau_{\mathrm{a}}^\ast$, a function of the withheld labels. Since $w_{\mathrm{a}}<1$, the label-free choice $\mathrm{FRR}_0=0$ sits strictly below the component-only fixed point.

\vspace{2pt}
The divergence is visible in practice. On the reference system's environmental axis, $w_{\mathrm{a}}=0.4677$. Ranking every structural-zero row above every threshold yields an EER of $0.1307$. The fixed point of $\mathrm{FAR}=w_{\mathrm{a}}\mathrm{FRR}_{\mathrm{a}}$ is also $0.1307$. Meanwhile, the true component-only value is $0.2090$.

A label-free reduction therefore settles on a different target rather than approaching the component-only value. Where Zhou and Wang~\cite{zhou2026eer} demonstrate a related invariance under monotone score transformations when the support is fixed, Proposition~4 is the complementary statement: adding structural zeros moves the fixed point by an amount only the withheld labels determine. Reporting AUC in place of EER would sidestep the distortion entirely, but EER remains the primary operating-point metric in anti-spoofing evaluations~\cite{asvspoof2021,asvspoof5}.

\subsection{Necessity of protocol-level correction}
\label{sec:necessity}

Proposition~4 bounds what can be done at the score level: the pooled distortion cannot be undone by post-hoc score manipulation, and requiring an explicit applicability flag would add a field the scoring procedure does not need. The corpus already defines the structural zero partition, and the official baseline computes the same indicator to mask class~$0$ in its loss. Since that partition is available where the scorer runs, each axis can be evaluated on the annotated subset alone, a single-line change that leaves the submission format untouched. Where the partition is unavailable at scoring time, as in cross-corpus evaluation or deployment, the component-only EER is unidentifiable and a summary that aggregates under pooling (Theorem~1) should be reported instead.

\section{Experiments}
\label{sec:exp}
\subsection{Setup}

CompSpoofV2~\cite{compspoof2026,esdd2} provides $175{,}361$ training and $24{,}864$ validation clips; we analyse the $27{,}605$-clip evaluation split, whose labels were released after the challenge and whose spoofed components include generators unseen in training. All mixture classes are $16$\,kHz mono; the structural-zero class is heterogeneous in sample rate and channel count, which \S\ref{sec:confounders_metric_recovery} treats as a confounder. Our systems are frozen encoders with linear or attentive probes, layers chosen on a generator holdout, each trained at three seeds: BEATs~\cite{chen2023beats} and EAT~\cite{chen2024eat} linear probes, a BEATs attentive head, and a two-encoder probe reading BEATs for the environmental axis and XLS-R for speech. The reference system is the released baseline, the only external system publishing per-clip scores, so \S\ref{sec:acoustic_vs_pooling} and \S\ref{sec:confounders_metric_recovery} are single-system results.\footnote{\label{fn:code}Code and the scripts that regenerate every number in this paper: \url{https://github.com/Shakhoyat/esdd2-pooling-audit}.}

Table~\ref{tab:spread} shows that holding a system fixed and changing only the constant $c$ assigned to structural zeros swings the reported environmental EER by up to $0.3970$. Under the true component-only protocol, this spread is identically zero.

This instability stems directly from the location of the point mass. Because all structural zeros receive an identical constant score, they collapse into a single point mass in the score distribution. The reported EER fluctuates depending on which side of the operating threshold this mass falls. The evaluation plan requests confidence scores without specifying a range, and its own worked example lists values such as $1.22$, $-1.54$ and $-1.89$~\cite{esdd2plan}, so unbounded logits are within the rules. For a probability-valued system, $c=0$ sits at the bottom of the range and the mass is rejected in full ($\mathrm{FRR}_0=1$): BEATs and EAT report $0.5382$ and $0.5400$. For a logit-valued system $c=0$ is an interior point, the attentive head and two-encoder spanning $[-25.0, 24.9]$ and $[-26.0, 34.4]$ on this axis, and the position of the mass relative to the threshold is incidental. It even varies with the seed: at $c=0.5$ the attentive head's seeds report between $0.1550$ and $0.4706$, while its component-only value stays between $0.1545$ and $0.1611$.

The two-encoder's near-invariance (a spread of $0.0031$) is the same artifact seen from the other side: its constants all sit within $0.026$ of the accept boundary, keeping every Table~\ref{tab:spread} cell within $0.0032$ of the floor. That is a property of an uncalibrated score range, not evidence of a robust protocol.

The distortion is not specific to the equal error rate. At the ASVspoof 5 cost
parameters~\cite{asvspoof5}, applied to the component decision rather than the whole-utterance
decision they were set for, scoring the reference submission as submitted gives a pooled minimum
detection cost of $0.9994$ against a component-only $0.5865$, and its residual against the weighted mean reaches $0.19$, where every
area residual stays below $10^{-15}$.

\subsection{Separating acoustic difficulty from pooling artifacts}
\label{sec:acoustic_vs_pooling}

A natural objection is that environmental spoofing is simply harder to detect than speech manipulation, so the higher pooled error reflects the model rather than the protocol. A controlled ablation separates the two. Evaluated only on mixture classes, where genuine component annotations exist, the environmental and speech heads reach comparable EERs of $0.2090$ and $0.1906$, an intrinsic difference of only $0.0184$. Reintroducing structural zeros under the benchmark mapping raises the environmental EER by $0.2246$ but the speech EER by only $0.0087$, so the reported $0.2343$ gap decomposes exactly into $0.2159$ from pooling alone ($0.2246 - 0.0087$), over $92\%$ of it, and the intrinsic $0.0184$.

The severity of the distortion is governed by the weighted false-rejection gap $w_0(\mathrm{FRR}_0-\mathrm{FRR}_a)$, evaluated at each axis's pooled operating point. On the speech axis ($w_0=0.3991$) this gap is $0.0169$ and the metric is nearly stable; on the environmental axis ($w_0=0.5323$) it widens to $0.3381$, driving the inflation. Because reference training explicitly masks class~$0$ across both loss functions, neither head received supervision on these instances: their output there is unspecified behaviour, not a measured deficiency. Masking is not idiosyncratic, either. The official baseline routes \texttt{original} clips away from both component detectors by construction~\cite{compspoof2026}, and at least one top-five submission masks both component losses on them, because component labels are defined only for mixtures~\cite{sit2026}.

One might instead train the environment head to emit bona fide on class~0, matching the mandated mapping. We ran this: supervising both component heads on class~0, all else fixed, lowers the pooled environmental EER by $0.20$ across three seeds and two frozen-BEATs feature configurations, with no gain in component-only detection. The heads learn to recognize original recordings (the environmental score's AUC for class~0 rises from $0.10$ to $0.71$), not synthesized environments, and the pooled value settles within $0.008$ of the Proposition~4 floor. It is still not a function of component performance: Table~\ref{tab:spread} shows the pooled number moving by $0.40$ under the fill value alone while the component-only value stays fixed.

Applicability looks easy to detect, but much of that ease is a format artifact. A trivial baseline using file formatting heuristics alone reaches an $\mathrm{F}_1$ of $0.9635$, because $93\%$ of structural zeros deviate from $16$\,kHz mono. Restricting to the $525$ structural zeros that are $16$\,kHz mono, scored against the $20{,}150$ mixtures of the split, that detector falls to chance ($\mathrm{AUC}=0.5000$), while the reference system's own submitted \texttt{original} score still separates the two at $\mathrm{AUC}=0.9957$. Because genuine mixed utterances are uniformly $16$\,kHz mono, this format-matched cohort removes the encoding cue, so $0.9957$ reflects the applicability signal itself rather than the file format. On the full split the same score reaches $0.9964$, yet the protocol still charges the system an environmental EER of $0.4336$.

The signal needed to fix the evaluation is therefore present in the submitted scores (Table~\ref{tab:endtoend}, gate $\gamma_a\ge\tfrac12$) and ignored by the protocol.

\section{Conclusion}
\label{sec:conc}

Component-level anti-spoofing routinely meets original recordings on which an axis does not apply. Pooling these structural zeros with genuine samples against a shared negative set leaves area-based summaries valid and distorts threshold-based ones: the environmental EER of a fixed model moves by nearly $0.40$ under the mandated rule, and published comparisons become unidentifiable. No label-free score reduction restores the component-only value, so the correction belongs in the protocol. The applicability partition is already available at scoring time, and each axis should be evaluated where it applies, a single-line scorer change that leaves the submission format untouched.
